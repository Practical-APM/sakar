# Sakar Baxi Portfolio

Premium textile-themed product portfolio. Scroll stitches a gold cord through grommets along an organic seam.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Debug overlay: [http://localhost:3000/?debug=1](http://localhost:3000/?debug=1)

## Stack

Next.js · TypeScript · Tailwind · Framer Motion · GSAP · SVG stitch engine
